文件清理工具（支持按后缀保护）

在浏览器里选文件夹 → 选择模式并勾选后缀 → 自动生成 bat 脚本，复制后到 Windows 双击运行即可。网页不会真的删任何文件。

需要 Chrome / Edge 桌面版浏览器。选择后网页只会读取文件列表，不会上传或修改你的文件。

② 选择模式并勾选文件后缀

模式：
红色 = 执行删除时会被删除 绿色 = 受保护 / 不会删除
归类说明： (无后缀) = 没有扩展名的文件（如 README、Makefile）； (隐藏文件) = 文件名以 . 开头的文件（如 .gitignore、.bashrc）。 这两类各自归为一个独立复选框，方便单独保护。注意：浏览器无法读取 Windows 的“隐藏”属性，隐藏文件仅按“以 . 开头”这一惯例识别。
